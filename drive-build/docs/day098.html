Day 98: Numbers and Place Value

Whole class opening (5 min)

Count backwards from 30 together.

Rotation

Teacher begins with A (15 min); rotates to C (15 min); finishes with B (15 min).

Group A, Beginning

Skill (NUM-07): Reads, writes and compares numbers up to five or six digits using place value

Activity (NUM-07-A3): Ordering large numbers, 12 min. Materials: blackboard, chalk, slates

  1. Write 5 five-digit or six-digit numbers on the board.
  2. Ask children to copy them on slates and put them in order from smallest to largest.
  3. One child comes to the board and explains their method: compare the number of digits first then the leftmost digit then the next.
  4. Do 3 rounds with different sets.

Check: Read this number and write the next one.

Group B, Middle

Skill (NUM-08): Reads, writes and compares large numbers (lakhs and crores) using place value

Activity (NUM-08-A2): Compare large numbers, 12 min. Materials: blackboard, chalk, slates

  1. Write two large numbers on the board (e.g. 34 50 000 and 34 05 000).
  2. Ask: which is bigger? Children discuss in pairs.
  3. One pair explains using place value.
  4. Write 4 more pairs. Children compare on slates and write > or < or =.
  5. Discuss: why do we start comparing from the leftmost digit?

Check: Read this number and write the next one.

Group C, Advanced

Skill (NUM-09): Finds factors, multiples and uses simple divisibility tests

Activity (NUM-09-A3): Divisibility tests, 15 min. Materials: blackboard, chalk, slates

  1. Write on the board: a number is divisible by 2 if it ends in 0, 2, 4, 6, or 8.
  2. Write 10 numbers. Children mark on slates which are divisible by 2.
  3. Now teach: divisible by 5 if it ends in 0 or 5. Children test the same 10 numbers.
  4. Teach: divisible by 3 if the sum of digits is divisible by 3. Show with 123: 1+2+3=6, and 6 is divisible by 3, so yes. Spend extra time on this rule — do 3 examples together on the board before children try alone.
  5. Children test 5 numbers for divisibility by 3.

Check: What is this number times that number?
