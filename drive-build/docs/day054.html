Day 54: Numbers and Place Value

Whole class opening (5 min)

Clap and count: teacher claps a rhythm and children count the claps.

Rotation

Teacher begins with A (15 min); rotates to C (15 min); finishes with B (15 min).

Group A, Beginning

Skill (NUM-04): Reads, writes and compares numbers up to 999 using place value (hundreds, tens, ones)

Activity (NUM-04-A1): Hundreds tens ones with bundles, 15 min. Materials: sticks, string, blackboard, chalk

  1. Give groups of 4 children a large pile of sticks (about 200) and string.
  2. Show: 10 sticks = 1 ten. 10 tens = 1 hundred (a big bundle).
  3. Write 365 on the board. Groups make 3 big bundles and 6 small bundles and 5 loose sticks.
  4. Write 3 more three-digit numbers. Groups build each one.
  5. Ask: which number used the most sticks? Why?

Check: Read this number and write the next one.

Group B, Middle

Skill (NUM-07): Reads, writes and compares numbers up to five or six digits using place value

Activity (NUM-07-A1): Lakh place value chart, 15 min. Materials: blackboard, chalk, slates

  1. Draw a place value chart on the board with columns: TTh TH H T O (ten-thousands thousands hundreds tens ones).
  2. Write 42538. Children read it aloud. Fill the chart together.
  3. Dictate 5 five-digit numbers. Children write them and fill charts on slates.
  4. Ask: what is the value of the 4 in 42538?
  5. Write two five-digit numbers and ask children to compare.

Check: Read this number and write the next one.

Group C, Advanced

Skill (NUM-09): Finds factors, multiples and uses simple divisibility tests

Activity (NUM-09-A3): Divisibility tests, 15 min. Materials: blackboard, chalk, slates

  1. Write on the board: a number is divisible by 2 if it ends in 0, 2, 4, 6, or 8.
  2. Write 10 numbers. Children mark on slates which are divisible by 2.
  3. Now teach: divisible by 5 if it ends in 0 or 5. Children test the same 10 numbers.
  4. Teach: divisible by 3 if the sum of digits is divisible by 3. Show with 123: 1+2+3=6, and 6 is divisible by 3, so yes. Spend extra time on this rule — do 3 examples together on the board before children try alone.
  5. Children test 5 numbers for divisibility by 3.

Check: What is this number times that number?
