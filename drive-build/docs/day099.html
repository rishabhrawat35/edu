Day 99: Numbers and Place Value

Whole class opening (5 min)

Skip-count by 2s up to 30 as a class.

Rotation

Teacher guides C (15 min); then B (15 min); then A (15 min).

Group A, Beginning

Skill (NUM-07): Reads, writes and compares numbers up to five or six digits using place value

Activity (NUM-07-A1): Lakh place value chart, 15 min. Materials: blackboard, chalk, slates

  1. Draw a place value chart on the board with columns: TTh TH H T O (ten-thousands thousands hundreds tens ones).
  2. Write 42538. Children read it aloud. Fill the chart together.
  3. Dictate 5 five-digit numbers. Children write them and fill charts on slates.
  4. Ask: what is the value of the 4 in 42538?
  5. Write two five-digit numbers and ask children to compare.

Check: Read this number and write the next one.

Group B, Middle

Skill (NUM-08): Reads, writes and compares large numbers (lakhs and crores) using place value

Activity (NUM-08-A3): Real-life large numbers, 12 min. Materials: blackboard, chalk, slates

  1. Tell children: India's population is about 140 crore. Write the number on the board: 1 40 00 00 000.
  2. Tell them the distance to the moon is about 3 84 400 km. Write it.
  3. Ask children to read each number aloud.
  4. Ask: which number has more digits? Which is bigger?
  5. Children write one large number of their own on slates and read it to a partner.

Check: Read this number and write the next one.

Group C, Advanced

Skill (NUM-09): Finds factors, multiples and uses simple divisibility tests

Activity (NUM-09-A4): Factor pairs race, 15 min. Materials: blackboard, chalk, slates

  1. Write a number on the board (e.g. 36).
  2. Teams of 3-4 children have 2 minutes to find all factor pairs: 1x36 2x18 3x12 4x9 6x6.
  3. Teams write their pairs on slates and hold up. Count who found the most.
  4. Do 3 rounds with different numbers (e.g. 48 and 60 and 30).
  5. Ask: which number had the most factors?

Check: What is this number times that number?
