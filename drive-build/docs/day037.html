Day 37: Numbers and Place Value

Whole class opening (5 min)

Count backwards from 30 together.

Rotation

Teacher guides group B first (15 min); then C (15 min); then A (15 min). Independent practice for others.

Group A, Beginning

Skill (NUM-03): Compares and orders numbers up to 99 (more, less, equal, smallest to largest)

Activity (NUM-03-A2): More or less game, 10 min. Materials: blackboard, chalk, slates

  1. Write two numbers on the board (e.g. 38 and 52).
  2. Ask: which is more? Children hold up right hand for the first number or left hand for the second.
  3. Ask one child to explain why.
  4. Now write three numbers. Ask children to write them on their slates from smallest to largest.
  5. Do 6 rounds with different pairs and triples.

Check: Which number is bigger? How do you know?

Group B, Middle

Skill (NUM-06): Reads, writes and compares numbers up to 9999 using place value

Activity (NUM-06-A2): Make the biggest and smallest number, 12 min. Materials: blackboard, chalk, slates

  1. Write 4 digits on the board (e.g. 3 7 1 9).
  2. Ask children to write on slates: the biggest four-digit number using these digits and the smallest four-digit number.
  3. Compare answers. Discuss: why is 9731 bigger than 1379?
  4. Do 4 more rounds with different digits.
  5. Include a zero in one round and discuss where zero goes.

Check: Read this number and write the next one.

Group C, Advanced

Skill (NUM-09): Finds factors, multiples and uses simple divisibility tests

Activity (NUM-09-A2): Multiples hopscotch, 15 min. Materials: chalk (for ground), blackboard, slates

  1. Draw a number line from 0 to 50 on the ground with chalk (or on the board).
  2. Ask one child to hop on multiples of 3 and say each number: 3 6 9 12...
  3. Another child hops on multiples of 4: 4 8 12 16...
  4. Ask: which numbers did both children land on? Write them on the board.
  5. Explain: these are common multiples.
  6. Children write the first 10 multiples of 5 and 7 on their slates.

Check: What is this number times that number?
