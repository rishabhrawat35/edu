Day 31: Data Handling and Patterns

Whole class opening (5 min)

Continue the number pattern: 2, 4, 6, ...

Rotation

Teacher begins with A (15 min); rotates to C (15 min); finishes with B (15 min).

Group A, Beginning

Skill (DAT-02): Sorts objects into groups by a property and reads simple pictographs

Activity (DAT-02-A1): Sorting the class, 12 min. Materials: blackboard, chalk

  1. Ask children to stand.
  2. Sort by one property: boys on the left, girls on the right. Count each group.
  3. Now sort by another: wearing shoes vs wearing sandals. Count.
  4. Draw the counts on the board as a simple pictograph (one stick figure = one child).
  5. Ask: which group has more? How many more?

Check: Look at this chart - how many in this group?

Group B, Middle

Skill (DAT-04): Reads and draws bar graphs and tables and answers questions from them

Activity (DAT-04-A1): Bar graph from data, 15 min. Materials: blackboard, chalk, slates

  1. Write data on the board: favourite sport — cricket 12, football 8, kabaddi 6, kho-kho 4.
  2. Draw axes: sports on the bottom, numbers on the side (scale of 2).
  3. Draw bars together — one per sport.
  4. Ask: which bar is tallest? How many more chose cricket than kho-kho?
  5. Children draw the same bar graph on slates.

Check: Look at this chart - how many in this group?

Group C, Advanced

Skill (DAT-06): Finds and describes number patterns and extends them

Activity (DAT-06-A1): Rule finder, 12 min. Materials: blackboard, chalk, slates

  1. Write a sequence: 3, 6, 9, 12, ___. Ask: what is the rule? (add 3). What is the 10th term? (30).
  2. Write: 2, 4, 8, 16, ___. Rule? (double).
  3. Write: 1, 4, 9, 16, ___. Rule? (square numbers).
  4. Children solve 3 pattern sequences on slates and write the rule.
  5. Ask: how is the doubling pattern different from the adding pattern?

Check: What comes next in this pattern?
