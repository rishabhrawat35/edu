Day 57: Operations

Whole class opening (5 min)

Finger addition: teacher shows fingers on both hands, class adds.

Rotation

Teacher starts with the group that struggled yesterday (15 min); then rotates to the other two (15 min each).

Group A, Beginning

Skill (OPS-04): Solves everyday word problems using addition and subtraction of two-digit numbers

Activity (OPS-04-A3): Real-life problems from school, 10 min. Materials: blackboard, chalk, slates

  1. Count the total children present today. Write the number.
  2. How many were present yesterday? (Ask children or use the register.)
  3. How many more or fewer today? Children solve on slate.
  4. If school has 72 books and class borrows 28, how many are left?
  5. Do 3-4 problems using real numbers from the school.

Check: Solve this addition and this subtraction.

Group B, Middle

Skill (OPS-11): Solves everyday word problems using all four operations

Activity (OPS-11-A3): Make your own problem, 10 min. Materials: blackboard, chalk, slates

  1. Write four numbers on the board: 12, 5, 60, 3.
  2. Challenge: use two of these numbers and any operation to make a true sentence. Children write on slates. (e.g. 12 x 5 = 60, 60 ÷ 12 = 5.)
  3. Now write: 120, 8, 15, 7. Children make as many true sentences as they can.
  4. Share answers. The child with the most correct sentences gets to write the next set of numbers.

Check: If 3 pencils cost 15 rupees, what do 5 cost?

Group C, Advanced

Skill (OPS-18): Adds, subtracts and compares fractions with like and unlike denominators

Activity (OPS-18-A3): Fraction subtraction with unlike denominators, 15 min. Materials: blackboard, chalk, slates

  1. Write 3/4 - 1/6 on board. Common denominator: 12. Convert: 3/4=9/12, 1/6=2/12. Subtract: 9/12-2/12=7/12.
  2. Children solve 4 problems on slates: 5/6-1/4, 2/3-1/5, 7/8-1/2, 4/5-2/3.
  3. Simplify answers where possible: 7/8-1/2 = 7/8-4/8 = 3/8.
  4. Call children to board to show working.

Check: Which number is bigger? How do you know?
