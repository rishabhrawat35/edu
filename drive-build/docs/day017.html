Day 17: Numbers and Place Value

Whole class opening (5 min)

The teacher writes a number; children say the next five numbers.

Rotation

Teacher starts with the group that struggled yesterday (15 min); then rotates to the other two (15 min each).

Group A, Beginning

Skill (NUM-02): Reads and writes numerals up to 99 and knows tens and ones

Activity (NUM-02-A1): Tens and ones with sticks, 15 min. Materials: sticks, string, blackboard, chalk

  1. Give each child 20 sticks and some string.
  2. Show how to bundle 10 sticks together with string to make one ten.
  3. Write 34 on the board. Ask: how many tens? How many ones?
  4. Children make 3 bundles of ten and 4 loose sticks.
  5. Call out 5 more numbers (up to 99) and children make bundles.
  6. Walk around and check.

Check: Read this number and write the next one.

Group B, Middle

Skill (NUM-05): Counts forward and backward in jumps of 2, 5 and 10

Activity (NUM-05-A1): Skip counting clap, 12 min. Materials: blackboard, chalk

  1. Class stands in a circle.
  2. Count by 2s: each child says the next number. If your number is a multiple of 10 you clap.
  3. Go around twice (up to about 40-60).
  4. Now count by 5s. Clap on multiples of 50.
  5. Now count by 10s. Clap on 100.
  6. Write the sequences on the board.

Check: Count these objects - how many are there?

Group C, Advanced

Skill (NUM-08): Reads, writes and compares large numbers (lakhs and crores) using place value

Activity (NUM-08-A1): Indian place value system, 15 min. Materials: blackboard, chalk, slates

  1. Draw the full Indian place value chart on the board: C TL L TTh TH H T O (crores ten-lakhs lakhs ten-thousands thousands hundreds tens ones).
  2. Write 3 large numbers (e.g. 45 23 678). Show how to read them with commas: 4 crore 52 lakh 36 thousand 78.
  3. Children copy and practice reading 3 numbers aloud.
  4. Ask: what is the value of the digit in the lakhs place?

Check: Read this number and write the next one.
