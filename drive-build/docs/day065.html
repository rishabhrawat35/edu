Day 65: Measurement

Whole class opening (5 min)

Quick quiz: how many days in a week? How many months in a year?

Rotation

Teacher begins with A (15 min); rotates to C (15 min); finishes with B (15 min).

Group A, Beginning

Skill (MEA-04): Measures length, weight and capacity using simple standard units (cm, m, kg, litre)

Activity (MEA-04-A1): Ruler measuring, 12 min. Materials: ruler or measuring tape, slates, chalk, blackboard

  1. Show a ruler and point out centimetre marks.
  2. Measure the length of a pencil — read the number.
  3. Each child measures their slate with the ruler and writes the length in cm.
  4. Compare: whose slate is longest?
  5. Draw a line on the board and estimate its length before measuring.

Check: Measure this - how long is it?

Group B, Middle

Skill (MEA-09): Measures and converts units of length (cm, m, km), weight (g, kg) and capacity (ml, l)

Activity (MEA-09-A1): Unit conversion relay, 10 min. Materials: blackboard, chalk, slates

  1. Write on the board: 1 km = 1000 m, 1 m = 100 cm, 1 kg = 1000 g, 1 l = 1000 ml.
  2. Call out a value: 3 km — children write in metres on slates.
  3. Call 5 conversions in quick succession.
  4. Check each answer on the board.
  5. Fastest and most accurate group wins.

Check: Measure this - how long is it?

Group C, Advanced

Skill (MEA-13): Understands volume and capacity and measures them with standard units

Activity (MEA-13-A1): Volume with cubes, 15 min. Materials: stones or bottle caps, slates, chalk, blackboard

  1. Stack stones or bottle caps in rows to build a 2x3x2 block.
  2. Count total: 12 units. This is the volume.
  3. Build a different shape with the same 12 units.
  4. Children build their own block on the desk and count units.
  5. Write: volume = length x width x height. Check with the count.

Check: Measure this - how long is it?
