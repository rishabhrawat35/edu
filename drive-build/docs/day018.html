Day 18: Numbers and Place Value

Whole class opening (5 min)

Clap and count: teacher claps a rhythm and children count the claps.

Rotation

Teacher starts with the group that struggled yesterday (15 min); then rotates to the other two (15 min each).

Group A, Beginning

Skill (NUM-02): Reads and writes numerals up to 99 and knows tens and ones

Activity (NUM-02-A2): Number dictation on slates, 12 min. Materials: slates, chalk, blackboard

  1. Say a number between 1 and 99.
  2. Children write it on their slates.
  3. Say: now write the number that is ten more.
  4. Check slates.
  5. Repeat with 10 different numbers.
  6. Ask 3 children to come to the board and write a number of their choice for the class to read aloud.

Check: Read this number and write the next one.

Group B, Middle

Skill (NUM-05): Counts forward and backward in jumps of 2, 5 and 10

Activity (NUM-05-A2): Backward counting relay, 12 min. Materials: blackboard, chalk

  1. Divide class into 2 teams.
  2. Write a start number on the board (e.g. 80).
  3. One child from each team takes turns writing the next number counting backward by 2.
  4. If a child writes the wrong number their team loses a point.
  5. Play 3 rounds: backward by 2 from 80 then backward by 5 from 100 then backward by 10 from 200.

Check: Count these objects - how many are there?

Group C, Advanced

Skill (NUM-08): Reads, writes and compares large numbers (lakhs and crores) using place value

Activity (NUM-08-A2): Compare large numbers, 12 min. Materials: blackboard, chalk, slates

  1. Write two large numbers on the board (e.g. 34 50 000 and 34 05 000).
  2. Ask: which is bigger? Children discuss in pairs.
  3. One pair explains using place value.
  4. Write 4 more pairs. Children compare on slates and write > or < or =.
  5. Discuss: why do we start comparing from the leftmost digit?

Check: Read this number and write the next one.
