Day 2: Numbers and Place Value

Whole class opening (5 min)

The teacher writes a number; children say the next five numbers.

Rotation

Teacher begins with A (15 min); rotates to C (15 min); finishes with B (15 min).

Group A, Beginning

Skill (NUM-01): Counts objects up to 20 and says how many there are

Activity (NUM-01-A2): Body counting, 10 min. Materials: none (children's bodies)

  1. Ask all children to stand.
  2. Call out a number from 1 to 20.
  3. Children clap that many times while counting aloud together.
  4. Then ask them to jump that many times.
  5. Pick one child to call the next number.
  6. Repeat 4-5 rounds.

Check: Count these objects - how many are there?

Group B, Middle

Skill (NUM-04): Reads, writes and compares numbers up to 999 using place value (hundreds, tens, ones)

Activity (NUM-04-A2): Three-digit number dictation, 12 min. Materials: slates, chalk, blackboard

  1. Say a three-digit number (e.g. 408). Children write it on slates.
  2. Ask: how many hundreds? How many tens? How many ones?
  3. Now say: write the biggest three-digit number you can make with 4 and 0 and 8.
  4. Children write and compare.
  5. Do 5 rounds with different digits.
  6. Ask 2 children to read their answers aloud.

Check: Read this number and write the next one.

Group C, Advanced

Skill (NUM-07): Reads, writes and compares numbers up to five or six digits using place value

Activity (NUM-07-A2): Number name writing, 12 min. Materials: blackboard, chalk, slates

  1. Write 63405 on the board.
  2. Read it aloud: sixty-three thousand four hundred and five.
  3. Write 4 more five-digit numbers. Children write the number name on slates.
  4. Now reverse: say a number name and children write the numeral.
  5. Discuss where commas go in the Indian system (after hundreds then after every two digits).

Check: Read this number and write the next one.
