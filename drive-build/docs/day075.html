Day 75: Numbers and Place Value

Whole class opening (5 min)

Clap and count: teacher claps a rhythm and children count the claps.

Rotation

Teacher guides group B first (15 min); then C (15 min); then A (15 min). Independent practice for others.

Group A, Beginning

Skill (NUM-05): Counts forward and backward in jumps of 2, 5 and 10

Activity (NUM-05-A3): Number pattern fill-in, 10 min. Materials: blackboard, chalk, slates

  1. Write a skip counting pattern on the board with blanks: 5 10 __ 20 __ 30.
  2. Children fill the blanks on slates.
  3. Now write a backward pattern: 90 80 __ 60 __ __.
  4. Do 6 patterns total: 2 counting by 2 and 2 by 5 and 2 by 10.
  5. Ask: what is the rule for each pattern?

Check: Count these objects - how many are there?

Group B, Middle

Skill (NUM-08): Reads, writes and compares large numbers (lakhs and crores) using place value

Activity (NUM-08-A3): Real-life large numbers, 12 min. Materials: blackboard, chalk, slates

  1. Tell children: India's population is about 140 crore. Write the number on the board: 1 40 00 00 000.
  2. Tell them the distance to the moon is about 3 84 400 km. Write it.
  3. Ask children to read each number aloud.
  4. Ask: which number has more digits? Which is bigger?
  5. Children write one large number of their own on slates and read it to a partner.

Check: Read this number and write the next one.

Group C, Advanced

Skill (NUM-09): Finds factors, multiples and uses simple divisibility tests

Activity (NUM-09-A2): Multiples hopscotch, 15 min. Materials: chalk (for ground), blackboard, slates

  1. Draw a number line from 0 to 50 on the ground with chalk (or on the board).
  2. Ask one child to hop on multiples of 3 and say each number: 3 6 9 12...
  3. Another child hops on multiples of 4: 4 8 12 16...
  4. Ask: which numbers did both children land on? Write them on the board.
  5. Explain: these are common multiples.
  6. Children write the first 10 multiples of 5 and 7 on their slates.

Check: What is this number times that number?
