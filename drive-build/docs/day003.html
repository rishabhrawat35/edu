Day 3: Numbers and Place Value

Whole class opening (5 min)

The teacher writes a number; children say the next five numbers.

Rotation

Teacher starts with the group that struggled yesterday (15 min); then rotates to the other two (15 min each).

Group A, Beginning

Skill (NUM-01): Counts objects up to 20 and says how many there are

Activity (NUM-01-A3): Counting walk, 15 min. Materials: leaves, slates, chalk

  1. Take children outside the classroom.
  2. Ask them to collect exactly 15 leaves (or any number up to 20).
  3. Bring them back and count together as a class.
  4. Ask: who has more? Who has fewer?
  5. Write the number on the board and ask children to copy it on their slates.

Check: Count these objects - how many are there?

Group B, Middle

Skill (NUM-04): Reads, writes and compares numbers up to 999 using place value (hundreds, tens, ones)

Activity (NUM-04-A3): Expanded form practice, 12 min. Materials: blackboard, chalk, slates

  1. Write 749 on the board.
  2. Show expanded form — this means writing a number as the sum of the value of each digit: 749 = 700 + 40 + 9.
  3. Write 5 three-digit numbers. Children write the expanded form on their slates.
  4. Now reverse: write 300 + 50 + 2. Ask: what number is this?
  5. Do 3 reverse rounds.
  6. Pick children to come to the board and explain.

Check: Read this number and write the next one.

Group C, Advanced

Skill (NUM-07): Reads, writes and compares numbers up to five or six digits using place value

Activity (NUM-07-A3): Ordering large numbers, 12 min. Materials: blackboard, chalk, slates

  1. Write 5 five-digit or six-digit numbers on the board.
  2. Ask children to copy them on slates and put them in order from smallest to largest.
  3. One child comes to the board and explains their method: compare the number of digits first then the leftmost digit then the next.
  4. Do 3 rounds with different sets.

Check: Read this number and write the next one.
