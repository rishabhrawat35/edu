Day 92: Operations

Whole class opening (5 min)

Finger addition: teacher shows fingers on both hands, class adds.

Rotation

Teacher guides C (15 min); then B (15 min); then A (15 min).

Group A, Beginning

Skill (OPS-09): Multiplies a two-digit number by a one-digit number and knows tables up to 10

Activity (OPS-09-A1): Multiplication on the board step by step, 12 min. Materials: blackboard, chalk, slates

  1. Write 23 x 4 on the board.
  2. Multiply ones: 4x3=12. Write 2 carry 1.
  3. Multiply tens: 4x2=8 plus 1 carried = 9. Answer: 92.
  4. Children solve on slates: 15x3, 24x5, 31x6, 18x4.
  5. Call 4 children to show their working on the board. Class checks together.

Check: What is this number times that number?

Group B, Middle

Skill (OPS-16): Uses decimal notation for money and lengths (metres and centimetres)

Activity (OPS-16-A1): Money as decimals, 12 min. Materials: blackboard, chalk, slates

  1. Write on board: 5 rupees and 50 paise = Rs 5.50. The dot separates rupees and paise.
  2. Write more: 3 rupees 25 paise = Rs 3.25. 12 rupees 75 paise = Rs 12.75.
  3. Children write on slate: 8 rupees 10 paise (Rs 8.10), 20 rupees 5 paise (Rs 20.05 — note the zero).
  4. Add: Rs 5.50 + Rs 3.25. Line up the dots. Answer: Rs 8.75.
  5. Children add 3 pairs on slates.

Check: Read this decimal and tell me its value.

Group C, Advanced

Skill (OPS-21): Uses simple ratio or unitary-method thinking in everyday situations

Activity (OPS-21-A3): Speed and distance problems, 12 min. Materials: blackboard, chalk, slates

  1. Write: A bus travels 45 km in 1 hour. How far in 3 hours? 45 x 3 = 135 km. How far in half an hour? 45 ÷ 2 = 22.5 km.
  2. Reverse: A car travels 180 km in 4 hours. Speed per hour? 180 ÷ 4 = 45 km/hour.
  3. Children solve 3 problems on slates: distance-speed-time using unitary method.
  4. Discuss: this is the same unitary method — find the value for 1 hour then multiply or divide.

Check: If 3 pencils cost 15 rupees, what do 5 cost?
