Day 146: Operations

Whole class opening (5 min)

Times-table chant: class recites the 2s table together.

Rotation

Teacher begins with A (15 min); rotates to C (15 min); finishes with B (15 min).

Group A, Beginning

Skill (OPS-19): Reads, writes, compares and adds decimals; converts between simple fractions and decimals

Activity (OPS-19-A2): Decimal addition and subtraction, 12 min. Materials: blackboard, chalk, slates

  1. Write 3.45 + 2.78 on board. Line up decimal points. Add: 5+8=13, write 3 carry 1. 4+7+1=12, write 2 carry 1. 3+2+1=6. Answer: 6.23.
  2. Write 5.03 - 2.67. Borrow as needed. Answer: 2.36.
  3. Children solve 4 problems on slates: 4.56+3.89, 10.00-6.75, 7.20+1.85, 8.04-3.56.
  4. Check by estimation: 3.45+2.78 is about 3.5+2.8=6.3.

Check: Read this number and write the next one.

Group B, Middle

Skill (OPS-20): Solves everyday problems using the four operations, fractions and decimals

Activity (OPS-20-A2): Fraction and decimal mix, 12 min. Materials: blackboard, chalk, slates

  1. Write: 1/2 + 0.3 = ?. Convert: 1/2 = 0.5. So 0.5 + 0.3 = 0.8.
  2. Write: 0.75 - 1/4 = ?. Convert: 1/4 = 0.25. So 0.75 - 0.25 = 0.50.
  3. Children solve 4 mixed problems: 1/5 + 0.4, 0.6 - 1/4, 3/4 + 0.5, 1.2 - 2/5.
  4. Rule: convert everything to the same form (all decimals or all fractions) then compute.

Check: Show me half of this. Now show one-fourth.

Group C, Advanced

Skill (OPS-21): Uses simple ratio or unitary-method thinking in everyday situations

Activity (OPS-21-A1): Unitary method introduction, 12 min. Materials: blackboard, chalk, slates

  1. Write on board: 5 notebooks cost 60 rupees. What is the cost of 1 notebook? 60 ÷ 5 = 12 rupees. What is the cost of 8 notebooks? 12 x 8 = 96 rupees.
  2. This is the unitary method: first find the cost or value of ONE unit, then multiply to find the cost of many.
  3. Children solve: 3 kg of sugar costs 135 rupees. Cost of 7 kg? (135÷3=45, 45x7=315.)
  4. Do 3 more problems on slates.

Check: If 3 pencils cost 15 rupees, what do 5 cost?
