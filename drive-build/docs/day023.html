Day 23: Shapes and Space

Whole class opening (5 min)

Point to something round, something square, something triangular.

Rotation

Teacher guides group A (15 min) while B and C practise independently; then guides B (15 min); then guides C (15 min).

Group A, Beginning

Skill (GEO-02): Sorts shapes by properties and identifies faces, corners, straight and curved lines

Activity (GEO-02-A2): Corner and face detective, 15 min. Materials: slates, chalk, box, ball, paper roll, book, bottle cap, blackboard

  1. Place 5 objects on the table: a box, a ball, a cone-shaped paper roll, a book, a bottle cap.
  2. Children touch each object and count its faces.
  3. On their slates they write the object name and number of faces.
  4. Ask: which object has no corners? Which has the most?
  5. Draw the 3-D shapes on the board and label faces and edges.

Check: Name this shape and count its sides.

Group B, Middle

Skill (GEO-04): Identifies angles, lines and the faces and edges of 3-D shapes; uses direction and grids

Activity (GEO-04-A2): 3-D edge counting, 15 min. Materials: box, paper, chalk, blackboard, slates

  1. Bring a box and a triangular paper shape folded into a prism.
  2. Children count the edges of the box by tracing each with a finger.
  3. Count the faces and vertices.
  4. Repeat for the prism.
  5. Write results on the board in a table: shape, faces, edges, vertices.
  6. Ask: what pattern do you see?

Check: Name this shape and count its sides.

Group C, Advanced

Skill (GEO-06): Identifies and measures angles and describes properties of 2-D and 3-D shapes

Activity (GEO-06-A2): Shape property table, 15 min. Materials: blackboard, chalk, slates

  1. First draw each shape on the board and say its name clearly: triangle, square, rectangle, parallelogram (like a pushed-over rectangle), pentagon (5 sides), hexagon (6 sides).
  2. Draw a table on the board: columns for shape name, sides, angles, parallel sides, lines of symmetry.
  3. Children come up one by one to fill in a cell.
  4. Discuss: which shapes have all equal sides? Which have all right angles?
  5. Children copy the table onto slates.

Check: Name this shape and count its sides.
