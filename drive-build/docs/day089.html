Day 89: Operations

Whole class opening (5 min)

Teacher writes a subtraction; children solve on slates.

Rotation

Teacher guides group A (15 min) while B and C practise independently; then guides B (15 min); then guides C (15 min).

Group A, Beginning

Skill (OPS-08): Adds and subtracts three-digit numbers including with carrying and borrowing

Activity (OPS-08-A1): Three-digit addition with carrying, 15 min. Materials: blackboard, chalk, slates

  1. Draw hundreds-tens-ones columns on board.
  2. Write 347 + 286. Add ones: 7+6=13. Write 3 carry 1. Add tens: 4+8+1=13. Write 3 carry 1. Add hundreds: 3+2+1=6. Answer: 633.
  3. Children copy and solve on slates: 456+378, 529+294, 183+459.
  4. Check: one child works each problem on the board while others check their own.

Check: Solve this addition and this subtraction.

Group B, Middle

Skill (OPS-15): Understands equivalent fractions and adds and subtracts fractions with the same denominator

Activity (OPS-15-A1): Equivalent fraction wall, 15 min. Materials: blackboard, chalk, slates

  1. Draw a rectangle on the board. Divide it into 2 equal parts. Shade 1 part: 1/2.
  2. Below it draw the same rectangle divided into 4 parts. Shade 2 parts: 2/4.
  3. They cover the same area so 1/2 = 2/4.
  4. Show 1/3 = 2/6 the same way.
  5. Children draw equivalent fraction pairs on slate: 1/4 = 2/8, 2/3 = 4/6.
  6. Rule: to find an equivalent fraction, multiply both the numerator (top number) and the denominator (bottom number) by the same number.

Check: Solve this addition and this subtraction.

Group C, Advanced

Skill (OPS-21): Uses simple ratio or unitary-method thinking in everyday situations

Activity (OPS-21-A3): Speed and distance problems, 12 min. Materials: blackboard, chalk, slates

  1. Write: A bus travels 45 km in 1 hour. How far in 3 hours? 45 x 3 = 135 km. How far in half an hour? 45 ÷ 2 = 22.5 km.
  2. Reverse: A car travels 180 km in 4 hours. Speed per hour? 180 ÷ 4 = 45 km/hour.
  3. Children solve 3 problems on slates: distance-speed-time using unitary method.
  4. Discuss: this is the same unitary method — find the value for 1 hour then multiply or divide.

Check: If 3 pencils cost 15 rupees, what do 5 cost?
