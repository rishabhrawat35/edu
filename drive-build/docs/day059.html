Day 59: Operations

Whole class opening (5 min)

Times-table chant: class recites the 2s table together.

Rotation

Teacher guides C (15 min); then B (15 min); then A (15 min).

Group A, Beginning

Skill (OPS-05): Understands multiplication as repeated addition and uses tables of 2, 3, 4, 5 and 10

Activity (OPS-05-A2): Bottle-cap groups, 15 min. Materials: bottle caps, slates, chalk, blackboard

  1. Give each pair 30 bottle caps.
  2. Say: make groups of 3. Children arrange caps in groups of 3. How many groups? 10. Write 3x10=30 on slate.
  3. Now make groups of 5. How many groups? 6. Write 5x5=25 (use 25 caps).
  4. Connect to the table: 5 times 5 equals 25.
  5. Repeat with groups of 2 and 4.
  6. Teacher writes the tables on the board for children to copy.

Check: What is the sum of these two numbers?

Group B, Middle

Skill (OPS-12): Understands fractions (half, one-third, one-fourth) and compares simple fractions

Activity (OPS-12-A2): Colouring fractions, 12 min. Materials: blackboard, chalk, slates

  1. Draw 3 circles on the board divided into equal parts: one into 2, one into 3, one into 4.
  2. Colour 1 part of the first circle. Write 1/2. Colour 2 parts of the second. Write 2/3. Colour 1 part of the third. Write 1/4.
  3. Ask: which fraction is the biggest? Children compare by looking at how much is coloured.
  4. Children draw 4 shapes on slate, divide each into equal parts, colour a fraction, and write the fraction.

Check: Which number is bigger? How do you know?

Group C, Advanced

Skill (OPS-19): Reads, writes, compares and adds decimals; converts between simple fractions and decimals

Activity (OPS-19-A2): Decimal addition and subtraction, 12 min. Materials: blackboard, chalk, slates

  1. Write 3.45 + 2.78 on board. Line up decimal points. Add: 5+8=13, write 3 carry 1. 4+7+1=12, write 2 carry 1. 3+2+1=6. Answer: 6.23.
  2. Write 5.03 - 2.67. Borrow as needed. Answer: 2.36.
  3. Children solve 4 problems on slates: 4.56+3.89, 10.00-6.75, 7.20+1.85, 8.04-3.56.
  4. Check by estimation: 3.45+2.78 is about 3.5+2.8=6.3.

Check: Read this number and write the next one.
