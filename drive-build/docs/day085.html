Day 85: Numbers and Place Value

Whole class opening (5 min)

Teacher shows fingers; children say the number they see.

Rotation

Teacher guides group A (15 min) while B and C practise independently; then guides B (15 min); then guides C (15 min).

Group A, Beginning

Skill (NUM-07): Reads, writes and compares numbers up to five or six digits using place value

Activity (NUM-07-A2): Number name writing, 12 min. Materials: blackboard, chalk, slates

  1. Write 63405 on the board.
  2. Read it aloud: sixty-three thousand four hundred and five.
  3. Write 4 more five-digit numbers. Children write the number name on slates.
  4. Now reverse: say a number name and children write the numeral.
  5. Discuss where commas go in the Indian system (after hundreds then after every two digits).

Check: Read this number and write the next one.

Group B, Middle

Skill (NUM-08): Reads, writes and compares large numbers (lakhs and crores) using place value

Activity (NUM-08-A1): Indian place value system, 15 min. Materials: blackboard, chalk, slates

  1. Draw the full Indian place value chart on the board: C TL L TTh TH H T O (crores ten-lakhs lakhs ten-thousands thousands hundreds tens ones).
  2. Write 3 large numbers (e.g. 45 23 678). Show how to read them with commas: 4 crore 52 lakh 36 thousand 78.
  3. Children copy and practice reading 3 numbers aloud.
  4. Ask: what is the value of the digit in the lakhs place?

Check: Read this number and write the next one.

Group C, Advanced

Skill (NUM-09): Finds factors, multiples and uses simple divisibility tests

Activity (NUM-09-A3): Divisibility tests, 15 min. Materials: blackboard, chalk, slates

  1. Write on the board: a number is divisible by 2 if it ends in 0, 2, 4, 6, or 8.
  2. Write 10 numbers. Children mark on slates which are divisible by 2.
  3. Now teach: divisible by 5 if it ends in 0 or 5. Children test the same 10 numbers.
  4. Teach: divisible by 3 if the sum of digits is divisible by 3. Show with 123: 1+2+3=6, and 6 is divisible by 3, so yes. Spend extra time on this rule — do 3 examples together on the board before children try alone.
  5. Children test 5 numbers for divisibility by 3.

Check: What is this number times that number?
