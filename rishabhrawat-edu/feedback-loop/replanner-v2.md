# 1.3 Update the next days' plan from the feedback (replanner v2)

- n8n workflow "1.3 Update the next days' plan from the feedback" (id fb2v2ReplanLite01). 1.2 (read the call and save it in the sheet) calls it, and it ends by running 1.4 (email the teacher) through its "Run 1.4 Email the teacher" node. It replaced "Old 1.3" (id 8yk18T7dbTzoon8V, kept but not used) on 2026-10-24. 1.1 is the 2 pm reminder.
- Steps: gather context with Sheets/Docs and Code (no AI) → Diagnose (gpt-5.4-mini) → Plan (gpt-5.5, returns only level/activity IDs) → Rule check in code (up to 2 retries, then it keeps the old plan and emails Config.admin_email) → AgenticOrg challenger (Config.challenger_agent_id; REVISE goes back to Plan once; errors are skipped) → Write (gpt-5.4-mini) plus a Code node that builds the Doc in the master layout, copying activity steps word for word → save the Doc, update the sheet, run 1.4.
- Task modes: replan the rest of the topic, the next topic's first 2 days when the reported day was a topic's last day, or an easier version of the day after a second No.
- Carried-over work (finish_first), prompt-only change on 2026-10-24: Plan writes one or two full sentences with the specific numbers. Write turns them into one 40–70 word paragraph with inline labels ("Left from Day 2: … Why: … Do: (1) … (2) … Time: … Check: …"). The Doc shows it as a single "Finish first:" paragraph, because the Doc-building node doesn't render line breaks.
- Test with the "Test with sample" trigger (Day 2, Partly, Group B confused by zero in the middle) on the Demo Teacher sheet: about 38 s, with 4 OpenAI calls (Diagnose 1, Plan 2, Write 1) and 1 AgenticOrg call. Old 1.3 took about 116 s, with 7 model calls and 4 tool calls.
- AgenticOrg sends a run to its human-review queue when the agent's own "HITL Condition" box matches. The challenger's box says "confidence < 0.93" and the structurer's says "confidence < 0.99"; this is separate from the "Confidence Floor" slider. The verdict comes back either way.
