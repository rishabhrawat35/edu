# 1.3 · Write (gpt-5.4-mini)

n8n workflow "1.3 Update the next days' plan from the feedback". Writes only the opening, rotation, finish_first paragraph, check questions, short sheet lines, and the email summary and change lines. "Build Docs" copies the activity steps word for word and drops any line with an ID or a labelling word. finish_first must stay ONE string, because Build Docs flattens line breaks.

Edit in n8n: the system message is on the "Write" node; the prompt is built in the "Write prompt" Code node (change only the text inside the quotes).

## System message ("Write" node)

```
You write short, plain notes for a maths teacher in a village school. Simple words, short sentences, no filler. Reply with JSON only.
```

## Prompt builder ("Write prompt" Code node)

```js
// Step 5 input: the checked plan, with titles and skills. The model writes only the short texts.
const c = $('Gather context').first().json;
const plan = $json.plan;
const G = ['A', 'B', 'C'];
const days = plan.days.map(d => ({ day: String(d.day), reason: d.reason,
  groups: Object.fromEntries(G.map(g => { const x = d['group_' + g.toLowerCase()]; const a = c.acts[x.activity_id];
    return [g, { skill: c.levels[x.level_id] || '', activity: a.title, materials: a.materials, finish_first: x.finish_first || null, said_today: c.result[g] || null }]; })) }));
const prompt = [
  'A maths teacher teaches grades 1 to 5 in one room, in three groups: Group A (Beginning), Group B (Middle), Group C (Advanced). Write the short texts for her updated day plans. She reads them in class, so be concrete.',
  '', 'What she said about Day ' + c.today.day + ':', JSON.stringify(c.feedback, null, 1),
  '', 'New plans:', JSON.stringify(days, null, 1),
  '', 'For each day write:',
  '- opening: a 5-minute warm-up the whole room does together on the day\'s topic, one or two sentences, with real numbers or objects.',
  '- rotation: one or two sentences giving the order, like "Start with Group B (15 min), then Group C (15 min), then Group A (15 min). The other two groups practise on their own." Start with the group that needs the most help.',
  '- for each group: finish_first (only if finish_first is given, else null): ONE string of about 40 to 70 words, with inline labels and inline numbering, built from that group\'s what_went_wrong, how_to_improve and what_is_left. Example: "Left from Day 2: the last 2 dictation rounds. Why: children wrote 408 as 48 when zero sat in the tens place. Do: (1) Say 408, 305, 710; children write them on slates. (2) Ask where the zero goes and why. (3) Show 4 bundles, 0 loose tens, 8 sticks. Time: 10 min. Check: write 506." No line breaks and no lists inside it, check (one question she can ask to check the skill, with real numbers or objects; never "Did you understand?"), sheet (a short line for her plan sheet, at most 8 words, no full stop).',
  'Also write, for her email: feedback_summary (one or two plain sentences, group by group, of what she told us about Day ' + c.today.day + '; do not start with the day) and changes (exactly one line per changed day, starting "Day N:", saying what each group will do, like "Day 3: Group B finishes dictation, then builds numbers with bundles. Groups A and C go ahead as planned.").',
  'Simple English, short sentences, no filler or praise words. Never use words that label children, such as weak, slow, struggling, behind, poor, bright or smart. No activity or level IDs.',
  '', 'Reply with JSON only:',
  '{"feedback_summary":"...","changes":["..."],"days":[{"day":"' + days[0].day + '","opening":"...","rotation":"...","groups":{"A":{"finish_first":null,"check":"...","sheet":"..."},"B":{...},"C":{...}}}]}',
].join('\n');
return [{ json: { prompt, plan } }];

```
