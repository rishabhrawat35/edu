# 1.4 · Email to the teacher (plain-text template, no AI)

n8n workflow "1.4 Email the teacher what changed in the plan", "Write email" Code node. The summary and the change lines come from 1.3's Write step (feedback_summary, changes).

```js
// Simple plain-text email. Input: teacher_email, sheet_url, day, topic, feedback_summary, changes[]
const j = $json;
const changes = (j.changes || []).slice(0, 4).map(c => '- ' + c).join('\n');
const subject = 'Your plan is updated after Day ' + j.day + (j.topic ? ' (' + j.topic + ')' : '');
const body = [
  'Hi,',
  '',
  'Thanks for telling us how Day ' + j.day + ' went.',
  '',
  'You told us: ' + j.feedback_summary,
  '',
  'What changes:',
  changes || '- No changes were needed.',
  '',
  'Your sheet has the new plans. Open them from the Plan column: ' + j.sheet_url,
  '',
  'Your maths helper',
].join('\n');
const raw = [
  'To: ' + j.teacher_email,
  'Subject: =?UTF-8?B?' + Buffer.from(subject).toString('base64') + '?=',
  'Content-Type: text/plain; charset=UTF-8',
  '',
  body,
].join('\r\n');
return [{ json: { subject, body, raw: Buffer.from(raw).toString('base64').replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '') } }];
```
