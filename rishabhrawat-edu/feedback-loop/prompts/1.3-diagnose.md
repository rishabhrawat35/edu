# 1.3 · Diagnose (gpt-5.4-mini)

n8n workflow "1.3 Update the next days' plan from the feedback". Says per group whether it is on track, needs a repeat or is ahead, plus the unfinished work and the cause in one line each. Output keys: groups[].group / status / pending / root_cause.

Edit in n8n: the system message is on the "Diagnose" node; the prompt is built in the "Diagnose prompt" Code node (change only the text inside the quotes).

## System message ("Diagnose" node)

```
You read a maths teacher's feedback on one day and say how each of her three groups is doing. Use only what she said. Be brief. Reply with JSON only.
```

## Prompt builder ("Diagnose prompt" Code node)

```js
const c = $json;
const prompt = [
  'A maths teacher reported on Day ' + c.today.day + '. Her class has three groups: Group A (Beginning), Group B (Middle), Group C (Advanced).',
  '', 'Her feedback:', JSON.stringify(c.feedback, null, 1),
  '', 'What each group did that day:', JSON.stringify(c.reported_day, null, 1),
  '', 'Skills (level_id: what the child can do):', JSON.stringify(c.levels, null, 1),
  '', 'For each group give:',
  '- status: "on_track" (she said Yes), "needs_repeat" (she said Partly or No, or work is left) or "ahead" (finished early or she asked for harder work).',
  '- pending: the unfinished work in one short line, or null.',
  '- root_cause: why it went wrong, in one short line from her words, or null. Do not guess.',
  'Reply with JSON only: {"groups":[{"group":"A","status":"on_track","pending":null,"root_cause":null},{"group":"B",...},{"group":"C",...}]}',
].join('\n');
return [{ json: { prompt } }];

```
