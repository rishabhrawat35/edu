# 1.3 · Plan (gpt-5.5)

n8n workflow "1.3 Update the next days' plan from the feedback". Picks level_id and activity_id per group for each day it may change, places unfinished work in finish_first, and gives one reason per day. The same node also builds the retry text (rule errors) and the revise text (AgenticOrg challenger problems).

Edit in n8n: the system message is on the "Plan" node; the prompt is built in the "Plan prompt" Code node (change only the text inside the quotes).

## System message ("Plan" node)

```
You plan the next days for a multi-grade maths class: grades 1 to 5 in one room, with Group A (Beginning), Group B (Middle) and Group C (Advanced). You pick only level and activity IDs from the lists you are given. Never invent an ID. Reply with JSON only.
```

## Prompt builder ("Plan prompt" Code node)

```js
// Builds the Plan prompt. Comes here first from Diagnose, again after a failed rule check or a REVISE from the challenger.
const c = $('Gather context').first().json;
const diagnosis = $('Read diagnosis').first().json.diagnosis;
const st = $json.state || { plan_calls: 0, fails: 0, challenge_round: 0 };
const allowed = c.scope.map(d => d.day);
const task = c.task === 'easier_day'
  ? 'The teacher said No twice for Day ' + c.today.day + '. Make an easier version of that day: the same level for each group, with a different, simpler activity (more hands-on, smaller numbers).'
  : 'Update the days below after the teacher\'s feedback on Day ' + c.today.day + '.' + (c.last_day_of_topic ? ' Day ' + c.today.day + ' was the last day of its topic, so the next topic\'s first days may change.' : '');
const lines = [
  task, '',
  'Groups: Group A (Beginning), Group B (Middle), Group C (Advanced).', '',
  'Her feedback:', JSON.stringify(c.feedback, null, 1), '',
  'How each group is doing:', JSON.stringify(diagnosis, null, 1), '',
  'Day ' + c.today.day + ' (the reported day):', JSON.stringify(c.reported_day), '',
  'Days you may change (current plan): ' + allowed.join(', '), JSON.stringify(c.scope_days, null, 1), '',
  'The days after them (for context only, do not change):', JSON.stringify(c.next_days), '',
  'Skills (level_id: what the child can do):', JSON.stringify(c.levels, null, 1), '',
  'Activities you may use, per group (activity_id | level_id | title | mode | minutes):',
  ...['A', 'B', 'C'].map(g => 'Group ' + g + ':\n' + c.candidates[g].join('\n')), '',
  'Rules:',
  '- Change only days ' + allowed.join(', ') + '. Add ONE extra day "<N>a" (for example Day ' + allowed[allowed.length - 1] + 'a) only if the unfinished work cannot fit.',
  '- Each day: one level_id and one activity_id per group, from the lists above. The activity must belong to that level.',
  '- The three groups are on three different levels each day.',
  '- Unfinished work comes first: put it in finish_first for that group on the first changed day, as one or two full sentences saying what is left from Day ' + c.today.day + ' and the exact numbers or items involved (no IDs). Otherwise finish_first is null.',
  '- A group that said Partly or No stays on the same level with a different activity. A Yes group moves on as planned. A group that is ahead may move up one level, no more.',
  '- Follow the teacher\'s "how to improve" when it fits these rules.',
  '- reason: one short line per day saying what changed and why, in plain words.',
  '',
  'Reply with JSON only, in this shape:',
  '{"days":[{"day":"' + allowed[0] + '","plan_status":"Updated","insert_after":null,"reason":"...","group_a":{"level_id":"...","activity_id":"...","finish_first":null},"group_b":{"level_id":"...","activity_id":"...","finish_first":"..."},"group_c":{"level_id":"...","activity_id":"...","finish_first":null}}],"pending_placement":"one line"}',
  'For an added day use "plan_status":"Added" and "insert_after":"<N>".',
];
if ($json.errors && $json.errors.length) lines.push('', 'Your last plan broke these rules. Fix every one and send the full plan again:', ...$json.errors.map(e => '- ' + e), 'Your last plan:', JSON.stringify($json.plan));
if ($json.revise) lines.push('', 'A reviewer found these problems in your last plan. Fix each one, or keep your choice and explain it in reason:', ...$json.problems.map(x => '- Day ' + x.day + ', Group ' + x.group + ': ' + x.problem + (x.fix_hint ? ' (' + x.fix_hint + ')' : '')), 'Your last plan:', JSON.stringify($json.plan));
return [{ json: { prompt: lines.join('\n'), state: { ...st, plan_calls: st.plan_calls + 1 } } }];

```
