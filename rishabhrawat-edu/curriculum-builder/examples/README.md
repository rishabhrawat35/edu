# Examples

Sample input configurations for the curriculum builder toolkit.

## Files

| File | Subject | Country | Notes |
|------|---------|---------|-------|
| `maths-india-grades1-5.yaml` | Mathematics | India | The configuration used for the maths-curriculum build. All fields documented. |
| `hindi-language-grades1-5.yaml` | Hindi Language | India | Shows how to configure for a language subject. Strands left for the researcher to propose. |

## How to use

1. Copy the example closest to your subject.
2. Edit the fields to match your context.
3. Place source files (textbooks, pedagogy documents) in the `sources/` folder.
4. Run the orchestration pipeline as described in `orchestration.md`.
